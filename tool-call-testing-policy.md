# Tool Call Testing Policy · PayPilot

**ДЗ_6 · 02.11.2026.** Стенд `325e2dd`, OpenAI `gpt-5-mini-2025-08-07`.
Фінальні команди на чистій копії: daily завершився без ERROR, baseline 4/4 PASS;
усі baseline 10/10 PASS. Це готовність до каскаду, не дозвіл на production.
Порожня форма: [tool-call-testing-policy-template.md](tool-call-testing-policy-template.md).

## 1. Система і межі

Перевіряємо дії агента підтримки: інструмент, payload, порядок, контракт,
стан після write, повтор і кеш. Оракули - доменний рушій, seed і спани;
текст відповіді не є доказом. Зовнішня доставка та production поза межею.

## 2. Прогноз і результат

взяті з курсу й прямо позначені як непереносні на OpenAI. Власного числового

Прогнози збережено в `baf9595`, `8199f5f`, `9e76dec`; вибірки локальні.

## 3. Текст, дія і крок діалогу

На межі API MockServer відтворює попередні відповіді моделі; реальні інструменти
відновлюють стан. Лише `live: true` іде в модель. Сесію, клієнта, номер кроку,
payload і результат читаємо зі спанів. Перед reset зберігаємо звіт, трейс,
версію сценарію й стан; перевіряємо `mock_answered`, щоб історія не стала платною.
У S1 мок тепер просить підтвердження; живий крок 4 містить явну згоду.
Попередній FAIL через додаткове підтвердження залишено в історії.

## 4. Три вимірники

| Вимірник | Сценарій і assertion на спані | level | gate / runs |
|---|---|---|---|
| Інструмент | S7: `check_limits` є, `get_transactions` немає | 1, 3, 4 | release / 5 |
| Параметри | S2: `create_dispute` для TX-0202, не TX-0204 | 1, 4 | release / 5 |

Додатковий дозволений read не ламає патерн. Перевірка імен не доводить,
що дозвіл стосувався тієї самої транзакції; це залишковий ризик.

## 8. Блокуючі перевірки і gate

| Інструмент | Форма до виконання | Ціна / законний сценарій, якому заважає |
|---|---|---|
| create_dispute | локальні права й валюта з TX; доменний eligibility; ключ ідемпотентності | бюджет локальної перевірки ≤10 мс плюс рушій; недоступний рушій затримує законний спір |
| send_statement | локальне зіставлення адреси власника, права, захист повтору | бюджет ≤10 мс; блокує законну нову, але ще непідтверджену адресу |
| неоднозначний незворотний write | оператор до виконання | запропонований SLA до 1 робочого дня; термінова дія чекає |

Числа тут - запропоновані бюджети, не виміряні p50/p95; бар'єри цією роботою
не впроваджено. Daily / 1: S1, S3, S4, S6 - стан, повтор, контракт після
виконаної передумови. Release / 5: S1O, S2, S3B, S5, S7, S8 - вибір моделі,
порядок, відмова та кеш. Для дозволу релізу: baseline 5/5 і нуль заборонених
writes із п'яти. Частотна ціль не є полем assertion. Повний release / 5 ще
не виміряно для всіх нових сценаріїв; фінальна перевірка baseline мала по одному.

## 9. Специфікація інструментів

Опис, input schema, output contract і доменні правила версіонуємо разом;
власник інструмента погоджує зміну, власник suite додає регресію. S3 окремо
перевіряє `eligible: boolean`, `checks: object` у daily; `ok` не замінює дозвіл.
Анотації MCP - заяви, які доводить suite; сам стенд не є MCP-сервером.

## 10. Вартість і кеш

S5: від другого виклику (`from_call: 1`) `cache_read_min ≥1000`, release / 5.
Історичний baseline: `[0,1536]`, далі `[1536,1664]`; D28: `[0,0]` у 5/5.
Кеш руйнують зміни префікса інструкцій, описів/порядку інструментів, змінні
дані перед стабільною частиною. Перший виклик може бути холодним.
Середня оцінка кроку: **$0.00181458 із кешем**, **$0.00207290 без кешу (D28)**,
відношення **1.14x**. Для тих самих baseline-токенів без знижки: **$0.00245970**.
Output різний, тому 1.14x не є чистим ефектом кешу. Тарифи на 01.11.2026:
input $0.25, cached $0.025, output $2 / 1M; формула
`((input-cached)*0.25+cached*0.025+output*2)/1e6`.
Джерело: https://developers.openai.com/api/docs/models/gpt-5-mini
Це оцінка завершених кроків, не рахунок; податки й збої не включено.
Сирий `cost_usd: null` не змінено; деталі: `evidence/s5-cost-estimate.json`.

## 11. Чого не покриває готова метрика

ToolCorrectnessMetric потребує окремого налаштування параметрів/порядку і сама
не відновлює крок N, не читає стан після write, output schema, кеш або повтор
ефекту. Жодна перевірка цього suite не оцінює текст відповіді. Assertion FAIL
не дає ненульового exit code ранера; CI має читати JSON. ERROR зупиняє серію,
завершені умови вже зберігаються. У проксі було ReadTimeoutException;
очікування підвищено з 20 до 60 с, фінальні команди пройшли без ERROR.

## 12. Залишковий ризик

| Не покрито | Наслідок | Чому живемо з цим зараз | Рішення |
|---|---|---|---|
| Прямий retry write та інші write-журнали | дубль, зайва ескалація чи виписка | локальна навчальна система; S4 має вужчу межу | відкласти production; власник інструментів додає тести |
| Зв'язок TX і дозволу, гонки | запис за чужим або застарілим дозволом | обмеження патерна явно вказано | посилити бар'єр до production |
| Потрібність дії, слова клієнта, стан production | формально правильна зайва дія | це межа детермінованого оракула | прийняти для ДЗ; judge і production-контроль окремо |
| Повна частота release, прогноз USD, рахунок | неповна статистика й бюджет | обмеження та невідомі значення відкриті | завершити release-серію перед релізом; прогноз не дописувати заднім числом |
